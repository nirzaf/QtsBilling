# QB-02 — Canonical IDs, value objects and contracts

**Status: DONE.**

## Deliverables

### New project `QtsBilling.Contracts` (`net10.0`, no third-party dependencies)

| File | Contents |
|---|---|
| `Abstractions/ApiErrorCodes.cs` | Stable machine-readable error codes (idempotency, sync, business outcomes) for ProblemDetails. |
| `Abstractions/Paging.cs` | Opaque-cursor paging (`PagingRequest`, `PagedResult<T>`); no unordered offset paging (F-14). |
| `Customers/CustomerDtos.cs` | `CustomerDto`, `SaveCustomerRequest`, `CustomerQuery`. |
| `Catalog/ProductDtos.cs` | `ProductDto`, `VariantPriceSnapshotDto`, `StockSnapshotDto` — catalog records carry no stock (F-12). |
| `Sales/SaleCaptureDtos.cs` | `SaleLineRequest`, `SaleCaptureRequest`, cash-only `PaymentCaptureRequest` (card PAN/CVV structurally impossible, F-07), `SaleCaptureResult`, `PaymentStatus`. |
| `Sync/SyncDtos.cs` | `SyncOperationEnvelope`, `SyncOperationReceipt`, `SyncOutcome`, `SyncChangeDto`, `SyncChangesPage` — at-least-once delivery with one terminal business outcome. |
| `Serialization/ContractJson.cs` | Shared wire JSON settings (UTC, camelCase, enums as strings, strict numbers). |
| `Serialization/CanonicalJson.cs` | Frozen canonical JSON + SHA-256 payload fingerprint used for idempotency (`IDEMPOTENCY_KEY_REUSED` / `SAME_KEY_DIFFERENT_PAYLOAD`). |

### New domain value objects `QtsModels/ValueObjects`

| File | Contents |
|---|---|
| `CurrencyCode.cs` | Validated three-letter currency with minor-unit digits (0/2/3). |
| `Money.cs` | `decimal`-backed money with explicit currency, checked arithmetic, single documented rounding boundary (commercial rounding). |
| `Quantity.cs` | Six-decimal quantity matching `numeric(18,6)`. |
| `ScaledDecimal.cs` | Checked exact conversions to/from scaled 64-bit integers for the local SQLite store (scale 10,000 money / 1,000,000 quantity); **rejects** excess precision and overflow instead of truncating (spec §3.1). |

rounding at the documented boundary, quantity precision, scaled-conversion rejection/overflow/round-trip,
and canonical-JSON stability (property order, `1`/`1.0`/`1.00`, whitespace, array order, null handling,
fingerprint stability and change detection).
