# QB-23 … QB-25 — historical import chain (retired)

**Status: RETIRED by Task 02. Replacement: native onboarding Tasks 18–20.**

The source-format inventory, transform and load CLI and its tests were removed from the current
solution. They were a one-way migration aid, not a supported runtime, and keeping a second import
path risked a silent compatibility fallback.

What remains in the current tree:

- `legacy_identifier_map` is a generic, read-only historical provenance table. It is not a
  compatibility path and is never written by the native importer.
- `external_record_links` is the native, append-only identity map written by
  `QtsBilling.DataImport` (Tasks 18/19). A repeated identical import reuses the target; a changed
  body or target is a conflict.
- `QtsBilling.DataImport` validates a signed native package, imports masters and approved openings
  atomically, and produces the canonical signed reconciliation report (Task 20).
- `TestQtsBilling/DataImport/` contains the focused native package, import and reconciliation
  tests; the real-PostgreSQL import and reconciliation scenario is `T20_06`.

The original source-format evidence, commands and mapping sample remain in Git history and in
archived backups. They are intentionally not part of the supported tree. No applied migration,
posted fact or unresolved cash operation was edited or deleted by this retirement.

See [QB-45](QB-45.md) for the replacement evidence.
