# QB-06 — Customers vertical slice (products/suppliers follow in later slices)

**Status: PARTIAL — customers are fully migrated to PostgreSQL behind the authenticated API and used by
the browser UI. Products, suppliers, units, categories/brands/groups, tax rates and discounts still run
on the legacy data-access services and move in QB-07+.**

## Deliverables (customers)

| Area | Contents |
|---|---|
| Storage | `customers` table: `business_id` + `phone_normalized` partial unique index (F-14), explicit `version` concurrency token, `is_active` for deactivation. |
| Endpoints | `GET /api/v1/customers` (search, keyset cursor paging, `includeInactive`), `POST`, `PUT /{id}` (optimistic concurrency via `If-Match`), `DELETE /{id}` (deactivates). |
| Tenant scope | Every query filters on the `qts:business_id` claim; a foreign id returns 404 (no IDOR). |
| Validation | Name required/≤ 200, e-mail shape/≤ 320, phone ≤ 40 (stored normalized), address ≤ 500 — validated server-side regardless of client. |
| Duplicates | Per-business normalized-phone uniqueness enforced by pre-check **and** the database index (`DUPLICATE_PHONE` 409 on both paths). |
| Contracts/UI | `CustomerDto`, `SaveCustomerRequest`, `ICustomerApiClient`; the Blazor page adds/edits/deactivates through the API (no direct data access). |
| History safety | Delete = deactivate: invoices/sales keep resolving the customer they were issued to; `includeInactive=true` exposes deactivated rows for audit. |

## Evidence (live host + PostgreSQL 18.6)

| Check | Result |
|---|---|
| Create 5 customers (distinct phones) | `201` each, UUIDv7 ids, `version: 1` |
| Duplicate phone in same business | `409 DUPLICATE_PHONE` (pre-check and unique index) |
| Same phone in another business | accepted (guard verified in QB-03 live SQL) |
| Update with correct `If-Match` | `200`, `version` 1 → 2 |
| Update with stale `If-Match` | `409 CONCURRENCY_CONFLICT` |
| Cursor paging (`pageSize=2`) | 3 pages / 5 ids, no duplicates, `nextCursor` until exhausted |
| Search + validation failures | `200` filtered, `400 VALIDATION_FAILED` with field errors |
| Deactivate | `204`, hidden from default list, visible with `includeInactive=true` |
| Cross-business id | `404` |
